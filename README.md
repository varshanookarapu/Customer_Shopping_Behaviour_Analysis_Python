# Customer Shopping Behaviour Analysis Python

The agenda of this project is to first understand the problem statement, then analyze customer shopping behavior in detail, clean the data, and perform exploratory data analysis (EDA) and document the data-cleaning steps along with the logical thought process behind each step.

I've used Google Colab for the initial data cleaning and exploratory data analysis (EDA)

I then exported the cleaned data to SSMS for further querying and analysis to address the relevant business questions

Following that, I created an interactive report using Power BI

Finally, I documented my key observations and recommendations in the [Customer Shopping Behaviour Report](https://github.com/varshanookarapu/Customer_Shopping_Behaviour_Analysis_Python/blob/main/Customer%20Shopping%20Behavior%20Report.docx)
